# 画像一覧
すべてオリジナルAI生成のイメージ画像。実在するSky Valueの社員・オフィス・サービス実績を示す写真ではありません。

- hero_city_large.webp：トップページのメインビジュアル（優先）
- hero_architecture_large.webp：トップページの代替メインビジュアル
- about_team.webp：ABOUTの抽象的な協業イメージ（写っている人物は実在の社員ではない）
- service_telecom.webp：通信・ネットワークセクション
- service_digital.webp：デジタル関連のセクション
- company_office.webp：会社案内（実際の本社写真ではない）
- hero_city.webp / hero_architecture.webp：小型画像版

画像は6面の元画像から切り出しているため、スマホ閲覧に向いた横長〜4:3構図です。ヒーローは大判ファイルを使用。各画像で実在企業の設備・事例・取引先などを表現しないこと。
