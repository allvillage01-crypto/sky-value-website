# Sky Value株式会社 公式サイト

Next.js（App Router）+ TypeScript + Tailwind CSS で構築した、1ページ完結型（LP形式）の静的サイトです。
データベース・サーバー・有料APIは使用していません。

## 1. ローカルでの起動手順

```bash
npm install
npm run dev
```

`http://localhost:3000` で表示を確認できます。

本番用の静的ファイルを生成する場合：

```bash
npm run build
```

`out/` フォルダに静的サイト一式が出力されます（データベース・サーバー不要で、そのままどのホスティングにもアップロードできます）。

## 2. 制作方針について（指示書との差異）

いただいた `Sky_Value_Website_Kit/04_ai_prompt/COPY_PASTE_PROMPT.md` には複数ページ構成（/about, /service 等）の案が含まれていましたが、
本文の制作指示書（1. 今回の目的 〜 3. ホームページの構成）で明確に「1ページ完結型（ランディングページ形式）」が希望として指定されていたため、
**本文の指示を優先し、1ページ構成（HOME内にABOUT/BUSINESS/COMPANY/CONTACTをセクションとして配置）で実装しました。**
将来的にページを追加したくなった場合も、`app/` にルートを追加するだけで拡張できる構成にしています。

ニュース機能・ブログ・お問い合わせフォームの実送信など、指示書「10. 今回実装しない機能」に該当するものは実装していません。

## 4. お問い合わせ方法の比較（A: メール誘導 / B: フォーム）

メールアドレス（info@skyvalue.jp）が確定したため、A案（mailtoリンク）で実装済みです。比較表は今後B案（フォーム）への切り替えを検討する際の参考として残しています。

| 比較項目 | A. mailtoリンク（メールアプリ起動） | B. 入力フォーム（送信） |
|---|---|---|
| 初期費用 | 0円 | 0円（フォーム単体） |
| 運用費用 | 0円 | フォーム送信を実現する仕組みにより異なる（下記参照） |
| 実装の手間 | 非常に小さい（`<a href="mailto:...">` のみ） | 中程度（送信先の仕組みを別途用意する必要あり） |
| スパム対策 | メールアドレスがHTMLに露出するため、クローラーに収集されやすい（軽減策：画像化・JS分割表示など） | reCAPTCHA等の対策を組み込みやすい |
| 個人情報の取り扱い | 送信者の端末のメールアプリから直接送られるため、サイト側はデータを一切保持しない | 送信経路（フォーム送信サービス）が個人情報を一時的に扱うため、そのサービスのプライバシーポリシー確認が必要 |
| 静的サイトとの相性 | ◎（サーバー不要でそのまま動作） | △〜○（Next.jsは静的出力のためサーバーに送信処理を書けない。Formspree・Googleフォーム埋め込み・Cloudflare Workers等、外部の送信先サービスが別途必要） |

**提案：** 今回の「制作費用・維持費用を無料にする」「データベースを使わない」という方針に最も合うのはA（mailtoリンク）です。
将来的に問い合わせ件数が増えてスパムや管理の手間が気になる場合に、B（外部フォームサービスとの連携）への切り替えをご検討ください。
どちらの場合も、**送信先メールアドレスが確定次第**、`components/Contact.tsx` を差し替えて公開してください。

## 5. ホスティングの比較（無料・商用利用）

| サービス | 商用利用 | 独自ドメイン | HTTPS | 備考 |
|---|---|---|---|---|
| **Cloudflare Pages**（推奨） | 利用規約・サービス固有条項に商用利用の明示的な禁止なし | 対応（CNAME追加 or ネームサーバー移管） | 無料・自動 | 静的サイトのホスティングとして実績が多く、帯域・ビルド回数の制限も緩やか |
| GitHub Pages | 公式ドキュメントで「ECサイト・商取引が主目的のサイト」は非推奨と明記。会社の紹介サイト（取引機能なし）はグレーゾーン | 対応（Punycode入力が必要） | 無料・自動 | ソースコード管理とホスティングが同じ場所になるのは便利だが、商用利用の線引きがCloudflareより曖昧 |
| Vercel（Hobbyプラン） | **不可**。Fair Use Guidelinesで「法人・クライアントワーク・商用サイト」は明確に対象外とされ、Proプラン（有料）が必要 | 対応 | 無料・自動 | 今回の「維持費用0円」方針には合わない |

**提案：** **Cloudflare Pages** を本命とし、ソースコードは GitHub 等で別途バージョン管理する運用を推奨します（ホスティングと保管場所を分離）。

## 6. 独自ドメイン（スカイバリュー.jp）について

契約状況のスクリーンショットが未着のため、**DNS設定・ネームサーバー変更は一切行っていません。**
一般的な技術情報として、以下は確定している事項です。

- 日本語ドメイン（IDN）はDNS上では常に Punycode（`xn--`から始まる形式）で登録されます。これはCloudflare Pages・GitHub Pagesを含むすべてのホスティングサービスに共通する、DNSプロトコル自体の仕様です。「スカイバリュー.jp」をPunycode変換した文字列を、ホスティング側の「カスタムドメイン」設定に入力する形になります。
- SSL証明書はCloudflare Pages・GitHub Pagesともに無料（自動発行）です。
- お名前.com側で必要な作業（ネームサーバー変更 or CNAME/TXTレコード追加）、既存メールサービスへの影響有無、維持費用以外の費用発生有無は、**スクリーンショットを拝見してから**個別に調査し、ご案内します。
